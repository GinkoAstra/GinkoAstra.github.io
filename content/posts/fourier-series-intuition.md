## 一个让傅里叶睡不着的问题

1807 年，傅里叶在研究热传导方程时断言：任何周期函数都可以表示为正弦与余弦的无穷和。当时的评审拉格朗日坚决反对——"用光滑的波去拼出不连续的方波？不可能。"

这个争论的本质问题是：**为什么叠加是合法的？**

先看热方程本身。一根长度为 $L$ 的金属杆，温度分布 $u(x,t)$ 满足：

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$$

分离变量 $u(x,t) = X(x)T(t)$ 代入，两边各得一个常数 $-\lambda$：

$$\frac{T'}{\alpha T} = \frac{X''}{X} = -\lambda$$

$X'' + \lambda X = 0$ 配上端点绝热/恒温边界条件，其解空间恰好由 $\sin$、$\cos$ 张成。**正弦波不是傅里叶拍脑袋选的基，而是微分方程自己的特征函数。** 这是整个理论的第一个直觉：算子的特征函数，天然是展开坐标。

## 系数从哪来：内积几何

假设 $f$ 以 $2\pi$ 为周期，我们猜：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos nx + b_n \sin nx \right)$$

怎么求 $a_n$？把函数空间看成内积空间，定义：

$$\langle f, g \rangle = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\,g(x)\,dx$$

在这个内积下，$\{1, \cos nx, \sin nx\}$ 两两正交，例如 $m \neq n$ 时 $\langle \cos mx, \cos nx \rangle = 0$。于是求系数就是**向基向量投影**——和线性代数里 $\vec{v}$ 在 $\hat{e}$ 方向投影一模一样：

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx, \qquad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx$$

> 傅里叶系数 = 函数在"频率为 $n$ 的波"方向上的坐标。这句话值回整篇笔记。

## 方波实验：拉格朗日错在哪

取方波 $f(x) = \operatorname{sgn}(\sin x)$。它是奇函数，所有 $a_n = 0$，而：

$$b_n = \frac{2}{\pi}\int_0^{\pi} \sin nx\,dx = \frac{2}{n\pi}\bigl(1 - (-1)^n\bigr)$$

即偶数项全灭，奇数项 $b_n = \dfrac{4}{n\pi}$，于是：

$$f(x) = \frac{4}{\pi}\sum_{k=0}^{\infty} \frac{\sin(2k+1)x}{2k+1} = \frac{4}{\pi}\left(\sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots\right)$$

部分和 $S_N$ 随 $N$ 增大确实逼近方波——但在跳变点附近总有一个压不下去的"过冲"，高度约为跳变量的 $8.95\%$，这就是 **Gibbs 现象**。拉格朗日的直觉在这里部分成立：点态收敛在不连续点确实出了问题，收敛只在一测度意义（$L^2$）下成立。这个故事的教训是：**换一套收敛定义，"不可能"就变成了"显然"。**

## 复数形式与频谱

用欧拉公式 $e^{inx} = \cos nx + i\sin nx$，级数压缩成一行：

$$f(x) = \sum_{n=-\infty}^{\infty} c_n e^{inx}, \qquad c_n = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(x)e^{-inx}\,dx$$

$|c_n|$ 对 $n$ 的图就是**频谱**——函数里"含有多少频率 $n$ 的成分"。信号处理里说的"傅里叶变换看频谱"，在级数这里已经全部发生了。

## 它在你的耳机里

MP3/AAC 压缩的核心步骤：把音频分帧，每帧做离散余弦变换（DCT，傅里叶级数的实数亲戚），然后按心理声学模型**删掉人耳听不见的频段系数**。你听到的每首歌，都是一次带损的傅里叶展开。
